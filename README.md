# Stev's Halloween Mod

Happy Halloween!!! This mod adds a bit of Halloween spirit to Minecraft with autumn colors, spooky mobs, festive food items, and more!

SHM is currently released only for NeoForge 1.21.1.

---

## Features

- **Halloween-themed Mobs**: Ghost, Vampire, Werewolf, Mummy, Frankenstein's Monster, and Devil spawn naturally in your world
- **Halloween-themed Food**: Many different types of candy, which you can craft or collect by killing spooky mobs; also Toasted Pumpkin Seeds!
- **Apple Trees**: New tree type with leaves that grow apples for you to harvest
- **Custom Foliage Colors**: Golden grass and autumn-colored trees
- **Revamped Title Screen**: Halloween-themed logo, panorama, and splash texts
- ...and lots more planned for future updates!

See the [wiki](https://github.com/Stev51/stevs-halloween-mod/wiki) for more detailed info!

---

It's recommended to use this mod alongside [Haunted Harvest](https://modrinth.com/mod/haunted-harvest) and [Farmer's Delight](https://modrinth.com/mod/farmers-delight)! This mod avoids overlapping content with these two, and feels more complete with them installed.

This mod is partially a remake of [Pipsqueak's Halloween Mod 2015](https://www.minecraftforum.net/forums/mapping-and-modding-java-edition/minecraft-mods/2550742-pipsqueaks-halloween-mod-2015-happy-halloween)! Credit to Pipsqueak737 for inspiring much of the content in this mod.
